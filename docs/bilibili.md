## 五、视频结构与口播稿

### 00:00–00:18 开场

**画面**：网盘首页，鼠标缓慢滑过文件列表；切到下载速度 / 上传队列。

**口播**：

> 这是一个网盘。
>
> 没有会员，没有广告，也没有下载到一半突然弹出来让你开超级会员的窗口。
>
> 因为它的服务器，就是我自己这台电脑。

### 00:18–00:50 为什么要自己做

**画面**：奶茶杯、代码编辑器、本地目录。

**口播**：

> 我一直想要一个简单的网盘：能放自己的资料，能给朋友发链接，最好别太贵。
>
> 但网盘的带宽最终是要花钱的。当服务器是别人的，限速、会员、广告，其实都是成本的一部分。
>
> 那如果服务器是我自己的呢？
>
> 这台电脑的磁盘、这台电脑的上行带宽，没有人为流量额外付费，也就不需要限速。
>
> 所以我写了 Milktea Cloud。它不绕过任何第三方服务，它只是把一台电脑，接成了一个网盘。

### 00:50–01:20 项目概览

**画面**：落地页 → 登录页 → 网盘首页。

**口播**：

> 这是它的首页。名字叫 Milktea Cloud，一杯奶茶的网盘。
>
> 技术栈很普通：Next.js 15、React 19，数据库用的是 Node 自带的 SQLite，文件直接存在本地磁盘。没有原生依赖，`npm install` 之后就能跑。
>
> 第一个注册的账号会自动成为站长。之后每个注册的人，都会得到一间只属于自己的空间。

### 01:20–02:00 注册与独立空间

**画面**：注册新账号；两个浏览器窗口并排，展示不同账号看到不同文件；尝试访问对方文件返回 404。

**口播**：

> 先注册一个账号。
>
> 这里的关键不是“公开”，而是“公开但互相看不见”。
>
> 我再用另一个账号登录。两个窗口，一个是我的文件，另一个是空的。搜索、下载、重命名、分享，所有请求在服务端都会带上所有者 ID，拿别人的文件 ID 也访问不到。
>
> 分享是唯一的例外，但分享必须由文件主人主动生成链接。

### 02:00–02:40 上传、暂停与断点续传

**画面**：拖拽一个大文件；上传队列；暂停；继续；完成；刷新页面后重新选择同一个文件。

**口播**：

> 上传支持拖拽。大文件会切成 8 MiB 的分片，最多三片同时传。
>
> 可以暂停，也可以继续。网络断了，只影响当前分片。
>
> 甚至刷新页面之后，重新选择同一个文件，它会认出上次的会话，从已经上传的分片接着传，而不是从零开始。
>
> 对经常传大文件的人来说，这个体验比“上传失败请重试”要好得多。

### 02:40–03:20 在线预览

**画面**：图片、视频、Markdown、CSV、代码、PDF 预览。

**口播**：

> 上传之后不用先下载。图片、视频、音频、PDF、Markdown、代码、CSV 都能直接打开。
>
> 视频支持拖动进度条，因为下载接口完整支持 Range。
>
> 文本类预览只读前 2 MiB，所以打开一个几 GB 的日志也不会把浏览器卡死。超出部分会提示下载完整文件。

### 03:20–04:00 分享链接、提取码与有效期

**画面**：文件菜单 → 分享 → 设置提取码和有效期 → 复制链接 → 无痕窗口打开 → 输入提取码 → 下载。

**口播**：

> 分享可以生成一条公开链接。可以设置提取码，也可以设置有效期。
>
> 拿到链接的人不需要注册，打开就能预览、下载，速度和你一样。
>
> 提取码不是明文存的，解锁凭证带签名，而且只对当前这条分享生效。文件删除之后，链接会立刻失效。

### 04:00–04:30 下载与 Range

**画面**：浏览器下载；`curl -I` 或下载器；拖动视频进度条。

**口播**：

> 下载接口从磁盘直接流出，不经过压缩、转码或队列。
>
> 它支持 Range，所以断点续传、视频拖动、IDM、aria2、Motrix 这些多线程下载器都能用。
>
> 再说一次：不设软件限速，但真正的上限是这台机器的上行带宽。

### 04:30–05:10 部署到公网

**画面**：终端 `npm run build && npm run start`；Nginx 配置；Cloudflare Tunnel 或域名访问；手机打开分享页。

**口播**：

> 部署也不复杂。`npm run build`，`npm run start`，默认跑在 3210 端口。
>
> 想公开访问，可以用 VPS 加 Nginx，反向代理时记得关掉请求缓冲、放大上传限制和超时；也可以用 Cloudflare Tunnel，把家里的电脑直接映射到一个 HTTPS 地址。
>
> 数据默认在项目的 `data` 和 `storage` 目录里，备份就是把这两个目录拷走。也可以把它们放到项目外面，重装项目不会丢。

### 05:10–05:50 诚实地说说限制

**画面**：设置页、磁盘空间、README 的安全说明。

**口播**：

> 它不是一个“完美的公共网盘”。
>
> 第一，速度取决于你的上行带宽，家庭宽带通常只有几十 Mbps。
> 第二，电脑要一直开着，断电就下线。
> 第三，公开注册默认开启，任何人都能注册、占用磁盘，所以公开部署前要么关闭注册，要么自己做好配额和管理。
> 第四，目前分享只支持单个文件，Office 文档不能在线预览，也还没有找回密码和 WebDAV。
>
> 这些限制我都写在 README 里了。它不是要取代谁，只是给愿意自己托管的人一个选择。

### 05:50–06:20 结尾

**画面**：项目首页 / GitHub 仓库 / 文件列表。

**口播**：

> 项目是 MIT 开源的，代码、部署配置和完整说明都在 GitHub。
>
> 如果你也有一台常开的电脑、NAS 或者 VPS，可以拉下来跑跑看。
>
> 它不会让别人的带宽变快，也不会绕过任何规则。它只是把属于你的磁盘和带宽，接成一杯自己的奶茶。
>
> 链接放在简介和置顶评论里。我们下期见。

## 六、录屏分镜清单

按这个顺序录，剪辑会很省事：

1. 落地页首屏（3 秒）
2. 注册 / 登录（5 秒）
3. 网盘首页：文件夹、文件、存储空间（5 秒）
4. 拖拽上传一个 20–50 MB 文件（10 秒）
5. 上传队列：暂停 / 继续（8 秒）
6. 图片 / Markdown / 视频 / PDF 预览（15 秒）
7. 重命名、移动、搜索（8 秒）
8. 分享：提取码 + 有效期（10 秒）
9. 无痕窗口：提取码解锁 + 下载（10 秒）
10. 第二个账号：空白空间 + 跨账号 404（8 秒）
11. 深色模式 + 手机端（8 秒）
12. 终端：`npm run build` / `npm run start`（5 秒）
13. Nginx / Cloudflare Tunnel 配置（5 秒）
14. 设置页：存储路径、磁盘剩余（3 秒）
15. GitHub 仓库 / README（5 秒）

录制建议：

- 浏览器缩放 100%，窗口 1440×900 或 1920×1080
- 演示文件名用“项目资料 / 旅行照片 / 品牌手册”，不要出现真实隐私
- 需要展示“跨账号隔离”时，用两个浏览器 Profile，避免 Cookie 干扰
- 上传演示文件不要太大，20–50 MB 足够展示进度
- 终端字号调大，关键命令加字幕
- 如果录到本机用户名 / 路径，后期打码

## 八、合规与避免误解

这部分很重要，公开视频和项目都需要：

- **不要说**“破解百度网盘”“绕过限速”“白嫖会员”“无限空间”
- **要明确**：这是一个自建服务，不修改、不伪造、不借用任何第三方客户端或账号
- **要明确**：限速上限取决于本机上行带宽，不是“真的无限快”
- **要明确**：公开注册默认开启，公开部署前应关闭注册或做好管理
- **要明确**：项目不做内容审核，使用者需要自行承担内容与合规责任
- **演示数据**：使用虚构文件，不出现真实姓名、手机号、身份证、住址、聊天记录
- **背景音乐**：使用有授权的音乐，保留授权记录
- **GitHub 链接**：发布前确认仓库是 Public，README、LICENSE、截图都能正常打开
